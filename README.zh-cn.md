## 项目背景

《工程控制论》是钱学森前辈的经典著作，书中的系统分析方法、反馈逻辑和状态空间理论不仅在工程领域影响深远，对当前的人工智能、复杂系统分析乃至跨学科的社会问题建模依然具有极高的指导价值。

然而，传统的图文 PDF 对大语言模型（LLM）和现代的知识检索增强系统（RAG）极不友好。

本项目旨在将《工程控制论》（第三版）全书进行高质信噪比的纯文本重构。我们（Landspark Digital Tech）将全书内容转化为包含数学公式（LaTeX 格式）和表格的 Markdown 文件，方便后来者在无需应对复杂格式阻碍的情况下，直接利用 AI 工具来阅读、调用和分析这套经典的工程理论。

## 数据处理流程

为了将几百页的复杂文档转化为结构化文本，我们使用了一套半自动化的处理流程：

- **初步提取**：使用 MinerU 对全书扫描件进行版面解析，初步提取出正文、数学公式和基础表格。
- **表格重构**：对于 MinerU 导出的复杂 HTML 格式表格，我们调用了大语言模型（LLM）将其逐一转换为原生的 Markdown 表格，以保证在各种阅读器下的兼容性。
- **正则清洗与人工介入**：通过正则表达式配合人工校验，我们将原本由于 OCR 错误识别出的英文标点批量替换为符合中文排版规范的中文标点。
- **非文本信息处理**：原书包含大量解释性图片。出于知识库构建的效率考虑，我们没有保留这些截图，而是将其删去，或替换文字性质的“图片占位符”（如保留了原图的编号和题注）。

## 已知问题与不足

在前期内容提取和清洗的过程中，由于批量正则替换的操作失误，我们意外删除了一部分原本应该保留的“图片占位符”。

因此，在阅读过程中，你可能会发现个别地方明显缺少了某张图的标记或题注。受限于整理的时间精力，这部分错漏未能完全弥补，敬请谅解。
